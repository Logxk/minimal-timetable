# 极简课表 (Minimal Timetable)

> **设计宗旨**：零冗余，极致性能。去除一切社交、广告、开屏、后台唤醒与冗余功能，启动即课表，响应在毫秒级。

## 📱 包含的两种形态（随心选用）

本项目提供两种形态，均已构建完毕存放于当前目录：

### 1. 极速 PWA 手机软件（全平台即开即用，推荐首选）
位于根目录下：`index.html`、`style.css`、`app.js`、`sw.js`、`manifest.json`、`icon.svg`。
* **跨平台兼容**：完美支持 Android、iOS (iPhone/iPad)、鸿蒙系统及各类手机浏览器。
* **离线秒开**：搭载 `Service Worker` 离线缓存，无网络/飞行模式下依然瞬间秒开。
* **独立桌面图标**：
  * **iOS (Safari)**：点击底部分享按钮 -> 选择「添加到主屏幕」，即可生成独立全屏 App，消除浏览器地址栏。
  * **Android (Chrome/Edge/微信/系统浏览器)**：点击右上角菜单 -> 选择「添加到主屏幕」或「安装应用」，即可生成独立桌面 App。
* **系统日历联动**：在右上角设置中支持一键导出标准 `.ics` 日历文件，可直接导入苹果日历或安卓日历，实现系统锁屏灵动提醒。
* **深色模式 (OLED Dark Mode)**：支持纯黑深色模式，OLED 屏幕像素完全关闭，极致省电。

### 2. 原生 Android 极限性能工程源码
位于 `android/` 目录下，专为追求极限原生体验的 Android 开发者准备：
* **单层 Canvas 绘制 (`TimetableView.kt`)**：彻底颠覆传统百级 View 嵌套的沉重结构，整周课表在单层硬件加速 Canvas 上单次 pass 完成绘制，单帧耗时 < 2ms。
* **零 GC 分配**：`onDraw` 中严格杜绝临时对象创建，从根本上消灭内存抖动和掉帧。
* **无任何多余权限**：不申请网络权限、不注册任何广播接收器，纯粹干净。

## 🚀 核心功能清单

1. **自动感知今日与当堂课程**：
   - 顶部日期栏自动高亮当前周几；
   - 实时自动检测正在上课的节次，课程卡片显示呼吸光环与“上课中”徽标。
2. **多节连堂自动合并**：
   - 支持跨节次连堂（如 1~2 节、3~5 节），高度按比例合并，紧凑工整。
3. **单双周与周次范围智能过滤**：
   - 每门课程支持设定有效周（如 1~16 周）以及「单周/双周/每周」，自动按周呈现，绝不混乱。
4. **极速交互**：
   - 点击空白格子：弹出轻量弹窗，秒加课程；
   - 点击已有课程：一键查看、编辑或删除。
5. **本地数据自由**：
   - 支持一键导出/导入 JSON 备份，换机数据无缝迁移。
